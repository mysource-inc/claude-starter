# claude-starter

株式会社マイソースのメンバー向けに、Claude Code の環境を Mac に一式入れる入口です。

Mac の「ターミナル」に次の1行を貼って、Enter を押してください。

```
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/mysource-inc/claude-starter/main/bootstrap.sh)"
```

始める前に、会社からの招待を2つ受け取っておいてください。

- Claude Team の招待メール
- GitHub の招待メール（キット本体の非公開リポジトリ）

このリポジトリには入口のスクリプトしかありません。スキルや設定は、GitHub にログインしたあとに非公開リポジトリから取得します。
